v0.9 Latest

September 3, 2026

Main Changes

  • OCR dictionary support (iOS 18+) (@GameFuzzy)

    Import Yomitan-compatible dictionaries in the app and look up words while reading.

    Commit
  • Suwayomi built-in source

    Read and track from a Suwayomi instance, just like Komga and Kavita.

    Commit
  • Auto scroll for webtoon reader

    Enable and press the play button to scroll without touching your device

    Commit
  • Fixed CloudFlare handling

    CloudFlare issues that caused external sources to break should be resolved.

    Commit
  • Disable sources option

    Temporarily disable sources without uninstalling them, e.g. if they are broken but could be fixed by an update.

    Commit
  • Improved library loading speed (@Amqx)
  • Improved webtoon reader performance

    Crashes due to memory usage, particularly when reading downloaded chapters, should be much less frequent.

    Commit

Other Features

  • Name field when creating backup
  • Improved iOS 27 support

    Later iOS 27 betas changed things and required some style updates.

    Commit
  • Double tap history tab to continue reader (@Amqx)
  • Prompt resuming interrupted library refreshes
  • Properly display failed downloads
  • Sortable editable list settings

    Sources that have editable list settings can now take into account the order of items.

    Commit
  • Improved animations

    Various transition animations (e.g. home, history, and source loading) have been updated to be more smooth.

  • Migrate and keep history option
  • Download external sources after restoring backup (@machsix)
  • Prefetch pages into next chapter according to preload setting (@Amqx)
  • Cover image processing support for sources
  • Text reader themes (@rbertus2000)
  • Dismiss expanded cover view with a swipe (@Amqx)
  • Tap on series title to global search (@Amqx)

Other Fixes

  • Improved backup information loading speed (@Amqx)
  • Library refresh not rescheduling and not sending notifications (@Zareix)
  • MangaBaka tracker not working
  • Table cells appearing with wrong selection state (@Amqx)
  • Double tracking entries creating for built-in sources
  • AniList tracker showing relogin alert unnecessarily
  • Backup export sheet not showing more than once
  • Migration sometimes freezing with many sources in use
  • Library not filtering correctly after reading
  • Handle potential source crashes gracefully

    WASM source programs would crash the app when the program crashed.

    Commit
  • Text reader fixes (@maerlin)

    Correct keyboard navigation and crashes

    Commit
  • Pages requiring processing by sources not cached correctly
  • History entries for the same date combining in random order

    If chapters have the same read date for the same series, they'll be sorted by chapter number descending.

    Commit
  • Memory issues when reading chapters with raw page image data
  • Reading in series view not working after migrating
  • Useless "Default" option for global reading mode

    This had the same behavior as "Automatic", but it has been removed.

    Commit
  • Chapter filters disappearing after changing sort
  • Webtoon pages sized wrong on iPad and macOS
  • Zooming not disabled on loading pages
  • Improved performance for reading large downloads
