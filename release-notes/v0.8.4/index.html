v0.8.4

July 3, 2026

Main Changes

  • Fixes for iOS 27

    Fixed settings pages freezing the app, along with other minor visual issues.

  • Improved backup restore time (@Amqx)

    Restores should now take seconds instead of minutes.

    Commit
  • Failed download page retrying (@pxseu)

    Less chance of missing pages in downloaded chapters from sources with aggressive rate limits.

    Commit
  • New chapter notifications (experimental) (@Zareix)

    When Aidoku refreshes in the background, notification(s) of new chapters should be sent if enabled.

    Commit

Other Features

  • Show days of week in the insights heatmap
  • Async JS execution source APIs
